# 学术录播与配音

适用于把论文汇报制作成可播放的幻灯片配音视频，以及配套字幕。关键词：备注讲稿、克隆音色、韵律、ASR 末词、SRT、逐页时间轴、静态画面压缩。

## 从代表性样片推进整片

先核对本次会议通知中的时长、容器格式、文件大小和命名要求。语言、露脸、合成语音政策分别记录为明确要求、未规定或未确认；“未强制露脸”不能推出“已确认接受 AI 配音”。

用户提供正式 PPT 且只要求录播时，保留原有页面与研究事实。以实际演讲者备注为讲稿依据，结构化副本用于核对；将录播所需的压缩、缩写读法等调整另存，不静默改写原稿。压缩重复解释时保留机制、实验条件、比较对象、数字、单位、指标口径及结论边界；涉及理论速率与实测 goodput 等不同指标时，保持区分。

盘点现有语音合成、幻灯片渲染、FFmpeg、ASR 能力和 CPU/GPU、内存、磁盘条件，再选择能实际产出的路径。先做包含专业词、数值、密集图表和跨页切换的短样片，试听和查看压缩后的画面，再生成整片；会议录播不默认需要数字人。

Windows 下按实际安装情况发现 FFmpeg/ffprobe、语音后端及幻灯片渲染程序；不假定存在 Bash、系统 `python3`、特定虚拟环境目录或 Linux 字体。命令使用当前 shell 支持的语法，程序与文件路径作为独立参数传入，并正确处理空格和中文；Python 可使用当前环境的解释器或 Windows 的 `py` 启动器。渲染工具或字体不同可能影响换行和图表显示，应检查本机渲染及最终压缩画面。

用实际合成时长安排页面。备注中的“预计若干秒”和按词数估算只能用于预算，不能作为最终切页时刻。总时长不合适时，优先消除重复叙述；必要的小幅语速调整应保持音高，并重新生成相应时间轴。无需为了凑足整数分钟加入明显空白。

## 音色、口音与韵律

把音色相似度、口音、术语可辨认度、停顿和自然度分开评价。克隆到相近音色，不代表保留了原说话方式；自然也不等于标准英美口音。用户希望保留自己的中式英语时，试听应关注其辅音起音、元音与词尾收音、词间衔接和停顿，沿用本次选择，不将某一种口音设为所有汇报的目标。

使用本人录音时保留原始文件，按静音、峰值和噪声情况决定裁剪或增益。输入采样率按实际后端要求转换，不把某个模型需要的 24 kHz 当通则。对能区分两种条件的后端，可对比仅使用说话人向量和同时使用参考音频、文本上下文的方式；后者是否保住韵律仍需试听。

遇到“同词每次像复读”的反馈，先检查生成粒度、缓存和参数。固定 seed 用于复现一次采样，其本身不能证明句内同词被逐词复制。用相同音色、文案和后处理，分别测试只换 seed、再调整 temperature；参考录音的语气和上下文也可作为后续变量。提高随机性不保证更自然，波形、时长或 ASR 结果不同也不等于听感改善。保留术语和数值回查，并让用户试听裁决。先核对后端实际支持的韵律控制，避免给不支持风格指令的模型添加无效提示词。

较长讲稿出现重复或疑似跳句时，先复查对应音频，再尝试拆开易混淆的复合句，或按几个完整句子分组生成。保留足够上下文和自然段内衔接，不逐词独立合成。记录片段的文本、参考条件、参数和实际时长，便于只重做有问题的部分。

本地推理开销较大时，复用后端支持的参考音频编码或音色配置，可避免每页重新分析同一段录音。这不代表消除了模型加载、量化、预填充和逐帧解码成本；并发和线程数按实测资源选择，不把某台机器的耗时写成通用性能结论。

需要缩短生成耗时、比较 CPU/GPU 后端或估算整片制作时间时，读取 [TTS 性能与后端比较](tts-performance.md)。

## 内容回查与字幕

ASR 用于查找疑点和辅助对齐，不能代替真人试听或证明声音自然。重点核对专业词、数字、小数、单位、否定、比较对象和句尾；使用当前环境可用的 ASR 或强制对齐工具，保留原始识别结果及人工修订的区别。

识别结果缺少末词时，先对同一音频改变识别器的收尾补静音或解码设置，区分音频截断与识别器尚未完成输出。未排除后者前，不直接修改 TTS 的结束策略或反复重录。中间句子疑似遗漏则单独回查；确认需要重做时修正音轨，不能仅在字幕中补上未说出的研究事实。

SRT 的正文以最终实际讲稿为依据修正术语拼写，时间来自实际音轨。可用强制对齐，或将 ASR 的词/BPE 时间戳与讲稿匹配，对少量识别拼写偏差插值；大段不匹配需要先回查音轨。匹配率只用于定位对齐问题，不代表转写准确率、口音相似度或自然度。经验性时间偏移需要抽听验证，不能跨模型照搬。

视频与字幕共用最终逐页时间轴。若音频使用速度系数 `tempo`，字幕换算为 `视频时间 = 页面开始时间 + 页前停顿 + 原始音轨时间 / tempo`；页间停顿、按帧取整后的时长和拼接结果都要纳入。修改音轨、语速或切页后重算字幕，不沿用先前样片或另一种声音的 SRT。

字幕按短语和句意分组，避免将句尾一个词孤立成闪现字幕，也避免在复合词的连字符处强行换行。把实验数值和器件型号规范显示为数字或标准名称，保留普通叙述的自然写法。每行长度、行数和阅读时间按目标语言检查；英文可从至多两行、每行 42 字符开始试排，再按播放器和实际阅读速度调整。

## 合成、压缩与一致性

静态幻灯片可用较低帧率配合 H.264/AAC，在保留较高分辨率的同时降低大小；含动画或运动画面时另行选择帧率。优先实际编码短样片，测量大小并查看关键图表，再决定压缩参数。

循环单张图片合成时，从音轨实际时长、速度系数及页前后停顿计算明确的片段时长，并按帧取整。不要只依赖 `-shortest` 判断静态循环视频何时结束；检查编码后的实际时长及结尾，确认没有多余画面。

分段生成、缓存复用或反复修订时，让记录能关联讲稿、音色条件、生成参数与种子、引擎版本、音轨校验值、页面偏移和语速。渲染前检查讲稿是否仍对应音轨，拼接前检查片段是否对应当前音轨和语速，字幕导出前核对音轨校验值与最终视频记录。分阶段保存原始音轨和失败样本，避免用旧音频配新字幕。

将编码和字幕先写入临时文件，检查成功后再替换成品。以最终文件检查容器、分辨率、实际时长、字节大小和完整解码；再从压缩后视频各页内部取帧组成联系表，检查顺序和边界，并放大关键图表的坐标、图例、单位与数值标签。原始 PPT 或渲染 PNG 清楚，不能替代压缩后检查。字幕需检查顺序、正时长、无重叠、换行和全片范围。

交付可播放文件、本次要求的字幕、实际时长和大小。说明实际完成的是哪些试听、ASR 回查、画面检查，保留仍需用户判断的自然度问题。
